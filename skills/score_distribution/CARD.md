# score_distribution

Human-provided diagnostic method for compatible, explicitly declared snapshots.

Protocol: `score-distribution-v1`. Reads supplied rows only. Model, evaluator, dataset, period, exposure, entity type and PL units must match. Missing or duplicated IDs remain explicit; fill rows never establish complete opportunity coverage.

Deterministic correctness and descriptive output do not establish causal attribution, research utility or Dream policy improvement. The reviewed Python wrapper is illustrative; installation invokes only the closed, source-pinned Jarvis builtin. Generated skills require OS isolation and independent validation.

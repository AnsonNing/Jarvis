# Release 0.12 — Selected entry research and private audit

The first owner-authorized real entry study needs a coherent path from a selected
model package to specialist preparation, independent Critic review and actual
Iris work. This change adds that path without restarting earlier workflows.
The public deliverable is the generic agent/admission/session machinery; model
assets, strategy source, private settings and all actual research results remain
in ignored private storage.

## Verified acceptance

The fixed-environment final regression passed **268 tests in 287.68 seconds**.
Ruff lint and formatting passed for 103 Python files. Mypy passed for 77 source
modules. The installed package is 0.12.0 and its dependency check passed before
the regression run. Installation did not run concurrently with testing.

The CLI `lab session-fixture` independently completed a two-stage artificial
session with all pending resource dimensions zero and VERIFIED quota accounting.
The fixture includes a measured integration intervention, compatible experience
transfer, a closed diagnostic capability proposal and separate method/policy
retrospective proposals. It makes zero external LLM calls and zero real Iris
submissions. Full-suite acceptance also retains the earlier synthetic Dream,
Critic, adoption, cost comparison and rollback paths. Linux CI adds the new
session command after the existing complete Research Lab acceptance.

## What changed

- Selected-package admission cross-checks owner selection, checksums, canonical
  source/model lineage, original completed cases and declared calendars.
- Local baseline import supports explicit calendar subsets while retaining and
  first evaluating the original raw ledger under its parent calendar.
- A side-specific basis-point entry-trigger control is independent of the
  predicted-score cutoff. Optional fields preserve old serialized identities.
- All declared LLM roles can pin a model and reasoning effort. The provider
  identity and actual CLI command include that effort when supplied.
- Explicit mean-PR and absolute daily-realized-MDD constraints select qualified
  PL improvements while preserving infeasible and unavailable results.
- Sequential reviewed sessions share full costs and conservative Iris quota.
  A failed integration effect blocks development. Contexts and experiences obey
  decision-time visibility, and unknown work remains unretried.
- An offline private notebook exports cowork inputs/outputs, source queries,
  critic decisions, experiments, costs, skills and retrospective proposal lineage.

## Limits

Compilation alone does not verify a hidden execution caller. Existing exposed
months cannot become independent validation. Daily-realized drawdown is not
intraday or portfolio mark-to-market risk. Missing opportunity/order/acknowledgement
data remain missing. Search results may contain only metadata or abstracts and
are tagged accordingly; retrieved implementations are not installed or run.

Retrospective method/policy proposals are not adopted or promoted by this
session. Capability fidelity does not establish utility. Actual independent
Dream/capability promotion still needs the separate complete-budget protocols,
sufficient distinct histories and fresh validation cohorts. There is no broker
connection or live trading. Detailed contracts and commands are in
[P13 entry research sessions](P13-entry-research-sessions.md).
